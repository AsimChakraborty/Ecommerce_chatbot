
E-commerce Customer Behavior Chatbot
Overview
This project is a Streamlit-based web application designed to analyze and provide insights into e-commerce customer behavior. It leverages a multi-agent system powered by Google's Gemini LLM, incorporating data preprocessing, customer segmentation, data analysis, and personalized recommendation functionalities. The dataset used in this project is sourced from Kaggle, specifically the "E-commerce Customer Behavior" dataset.
The application allows users to:

Analyze customer behavior through queries (e.g., customer segment characteristics, spending patterns, satisfaction levels).
Generate personalized recommendations for customers based on their segment and spending behavior.
Visualize customer data and query results interactively.
