# 🛍️ E-commerce Customer Behavior Chatbot

A Streamlit-based AI-powered chatbot that analyzes e-commerce customer behavior and delivers intelligent insights using Google Gemini and LangChain. This multi-agent system can answer questions, segment customers, and provide personalized recommendations based on shopping behavior and satisfaction levels.

---

## 🔍 Overview

This project is a Streamlit web application designed to analyze and provide insights into e-commerce customer behavior. It uses a multi-agent system architecture powered by **Google Gemini LLM** and **LangChain**, supporting:

- Data preprocessing
- Customer segmentation
- Interactive analytics
- Personalized recommendation generation


---

## 🛠️ Tech Stack

- **Streamlit** – UI for interactive web application  
- **Google Gemini (LLM)** – Natural language understanding and reasoning  
- **LangChain** – Multi-agent orchestration and prompt handling  
- **Pandas / NumPy / Matplotlib / Plotly** – Data analysis & visualization
